### Intermediate · [`Examples2/`](Python-Learning/Examples2)

| Project | Idea |
|---|---|
| 🎂 Age Calculator | Exact age from a birth date, leap years included |
| ⏰ Alarm Bot | Tkinter alarm clock with sound (Windows) |
| 🎨 ASCII Art Generator | Turns an image into ASCII art with OpenCV |
| 🎧 Audio Book Generator | Reads a PDF aloud with gTTS |
| ⏳ CountDown Timer | Tkinter countdown timer GUI |
| 🤖 Custom GPT | Chat with your own documents (LangChain + OpenAI + Chroma) |
| 🏋️ Workout Playlist Generator | Builds HIIT playlists on Spotify / YouTube Music |
| 💸 Expense Splitter | Splits shared bills among a group |
| 📹 Facebook Video Downloader | Downloads a video from its URL |
| 🌍 Geographic Distance | Distance and travel time between places with geopy, pytest-tested |

Each project is self-contained. Install its `requirements.txt` if it has one, then run it:

```bash
cd "Python-Learning/Examples2/Geographic Distance"
pip install -r requirements.txt
python geographic_distance.py
```
